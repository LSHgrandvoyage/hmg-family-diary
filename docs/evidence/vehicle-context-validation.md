# 차량 기억·녹음 위치 검증 — 2026-11-08

[설계/SDK 근거](../research/vehicle-memory.md). FR-016/017, 헌장1.2.0, 제품 정의·데이터 모델·포트/API 계획·T041~T043을 추가했다. 실제 차량 수집/DB/동기화 완료는 아니다.

## 구현 범위

- 일기별 차량 스냅샷: 별명·제조사/모델·차종·연식·선택적 번호. 번호 보기/가리기.
- 녹음 시작 위치와 시각: 한국 시간으로 표시하고 이야기 속 방문지와 구분한다. 가상 위치 또는 미확인 상태.
- 차량별 보관함: 모델/별명 검색, 같은 차량 ID의 과거 일기 조회. 월별 묶음과 기간 선택 유지. 최근 카드도 선택한 차량을 따른다.
- 순수 도메인 함수: 프로필과 위치를 복사·freeze하여 원본 프로필 수정이 과거 기록에 전파되지 않음. 관측 시각 최신성 정책. 이 함수는 DB 영속성을 구현한 것이 아니다.

## 남은 검증

차량 모델/번호 자동 조회는 반환형·지원 여부 미검증이다. 위치 API는 문서 확인 단계이며 실제 차량 위치/관측 시각 단위/품질/좌표→장소명 변환 미연결이다. 녹음 시작 시 수집은 Android capture adapter에서 연결해야 한다. 웹 브라우저 위치를 요청하지 않는다.

실제 iPhone/iPad Safari·차량 화면·인증된 저장/동기화는 미검증이다. 가상 프로필 두 개는 차 교체 후 회상 UX 예시이며 활성 차량 두 대 연결을 구현한 것이 아니다. 재방문 회상·차량 기념일·충전 맥락·주행 거리 기능은 후보 문서만 작성했고 구현하지 않았다.
