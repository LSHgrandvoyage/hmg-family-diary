# 사진·일기 목록·검색

상태: 웹/에뮬레이터 구현 / 실기기 경계 검증 잔여. 정리일: 2026-11-13. 작업 브랜치: dev.
이번 문서는 사용자 승인에 따라 기존 구현·기록을 사후 분리했다. 구현 전에 작성된 명세라고 주장하지 않는다.
이전 식별자: FR-009, FR-011, FR-018, FR-019; C003, C009~012, C015~018, C024, C028, C029. [전체 색인](../README.md), [이전 명세](../archive/2026-11-13-before-split/spec.md).

## 사용자 가치와 수용 시나리오

1. 사진 추가 직후 상태가 보이고, 오류에서 기존 사진이 유지된다. 새 사진이 먼저 보이며 확대·스와이프·옵션 삭제가 일관된다.
2. 검색 조건을 조합/초기화하고 다른 가족의 기록·사진을 볼 수 없다. 주행에서는 사진 요청도 차단한다.

## 현재 요구사항

- **LIB-001**: 목록은 기록 시각을 기준으로 제공하고 검색에 검색어·차량 조건을 통합한다. 미확인 차량은 중복 선택지로 나누지 않고 선택한 카드만 강조한다.
- **LIB-002**: 휴대폰에서 선택한 사진을 추가하고 양쪽에서 본다. 사진은 최신 추가 순서이며 차량에서 파일 선택기를 요구하지 않는다.
- **LIB-003**: 사진 선택 대기·검사·업로드·실패를 표시한다. 10MiB 초과·빈 파일·미지원 형식·해상도 한도·8장 초과를 알리고 서버 검증을 유지한다. 지원하지 않는 iPhone HEIC를 성공으로 표시하지 않는다.
- **LIB-004**: 사진의 비율을 보존하고 잘라 채우지 않는다. 모바일은 스와이프로 탐색하고 추가 진입은 마지막 사진까지 넘길 필요가 없어야 한다. 사진 없는 장식 칸을 실제 사진 옆에 반복 표시하지 않는다.
- **LIB-005**: 그날의 사진 가로 점3개에 관리 옵션을 모으고 일기 삭제도 카드 옵션에 둔다. 사진/일기 삭제 전 확인하고 삭제 동기화가 반영되기 전 완료를 과장하지 않는다.
- **LIB-006**: 위치 기반 지난 기록 회상은 같은 가족의 과거·미삭제 기록만 사용한다. 위치 없음/stale이면 미확인으로 표시하고 자동 재생·상시 추적을 하지 않는다. 차량 탐색은 주차에서만 허용한다.
