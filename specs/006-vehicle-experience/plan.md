# 차량 맥락·테마·설정·화면 — 구현 계획/현재 구조

2026-11-13 사후 정리. [명세](spec.md)와 [작업](tasks.md)을 함께 읽는다.

## 현재 구조

`VehicleTheme`, `VehicleInfoLookup`, `RecordingLocation`, `MemoryContextStore`와 faithful theme/settings 자산을 사용한다. 현재 자동 테마는 OS uiMode를 기준으로 하며 실차 터널 신호 성공을 주장하지 않는다.

공통 데이터·계약은 [001](../001-family-trip-memory/plan.md)에서 연결한다. 변경 시 사용자를 위한 수용 조건부터 명세에 반영한다.

## 의존성과 검증

헌장2.2.0의 원본 불변·가족 격리·주행 제한·검증 환경 구분을 유지한다.
연결/미디어/화면을 가로지르는 변경은 상대 기능 ID를 명시한다. 기존 증거와 이번 실행 결과를 구분한다.
신규 작업은 spec → plan/계약 → tasks → 정합성 검토 → 구현 → 검증/증거 → dev 커밋 순서다.

## 미해결 의존성

- 실차 모델/연식/환경 신호 지원과 터널 자동 전환 검증.
- 차량 거리·시간·목적지 추가 연계는 공식 API 확인 후 별도 명세.

## C041 — 제공 로고 적용 (구현 전 계획, 2026-11-13)

- UX-007의 원본 SVG를 faithful/brand 자산으로 보관한다. 웹 공통 rail과 모바일 보관함 헤더에서 재사용하고 favicon도 같은 파일을 사용한다.
- Android에서는 원본 도형을 VectorDrawable로 변환한다. 앱 내부에는 원본 정사각형 로고, 런처에는 배경/전경을 분리한 adaptive icon을 사용한다. 전경은 마스크 안전 여백 안에 배치한다. 기존 알림용 아이콘은 유지한다.
- ExactDiaryView의 로컬 자산 허용 목록에 SVG MIME만 추가한다. 기존 호스트/경로/네트워크 제한을 유지한다.
- 008 초기 안내와 native fallback rail도 같은 벡터를 참조한다. 동의 상태·진입 조건은 변경하지 않는다. 007 제출 APK는 버전 0.2.4/code 5로 만들고 최종 ZIP 한 개를 갱신한다.
- 독립 headless 브라우저에서 모바일 좁은 폭/가로·세로, 차량 녹음·일기·설정·주행, 양쪽 테마의 로고 로딩·비율·겹침을 확인한다. Android 빌드와 실제 WebView 자산 로딩, 앱 실행 아이콘을 에뮬레이터에서 확인한다.

정합성 검토: 기능 소유는 006, 공유 화면 004/008과 제출 007에는 기존 동작을 유지한다. 원본 SVG는 사용자 제공 브랜드 자산이며 개인 기록을 포함하지 않는다. 외부 네트워크·오디오 권한·동기화 계약 변경은 없다.

## C043 — 모바일 연결 흐름과 주행4개 화면 (구현 전 계획)

모바일 theme-shortcut에만 투명 배경/테두리 제거를 적용한다.44px 영역과 포커스 스타일을 유지하며 테마 전환이 미디어나 폼을 재생성하지 않게 한다.

정합성 검토:003 SYNC-009/006 UX-008/004 PLAY-008~009가 소유한다. 사용자 참조 이미지가 이전 C032 레이아웃을 대체한다. 일기 본문 접근·가족 격리·동의·원본 보존·TTS 정지 후 처음부터 재생은 유지한다. 원본 길이를 TTS 길이로 쓰지 않는다. 신규 메타데이터 계약과 오류/빈 목록/주차 복귀·오디오 전환을 검증하고 라이트/다크 및 모바일 작은 폭에서 확인한다.

## C044 — 주행 자막·동의 화면·창 크기·재생 연속성 (구현 전 계획)

viewport에서 CSS 설계 폭/높이를 실제 가용 영역에 맞게 계산한다. 비율을 유지해 확대/축소하고 콘텐츠 영역은 남은 높이를 사용한다. 주행 카드/주차 페이지에 가변 높이를 적용하며 재생바 높이를 레이아웃에서 확보한다. 가족 패널에서 중복 버튼만 제거한다.

정합성 검토: 헌장2.3.0에 사용자 요청의 제한된 주행 STT 표시 예외를 먼저 반영했다.002 REC-007,004 PLAY-010,006 UX-009,008 ENTRY-007이 소유하며 원본·DB·동기화 보관 계약은 바꾸지 않는다. 연결 상태를 녹음 동의로 간주하지 않는다. 개인정보 안내는 현재 동작의 프로토타입 안내로 한정하고 법적 적합성을 주장하지 않는다. 실제1682×1210 창/1280×720 참조·양쪽 테마·모바일·D/P 전환·동의 미선택/부분/전체/해제·주행 bridge 제한을 검증한다.

## C045 — 재생 통합·목록 페이지·STT 줄 흐름 (구현 전 계획)

차량 목록 상단의 개수별 이어듣기 버튼을 제거하고 공통 플레이어의 이전/토글/다음·방식 전환을 사용한다. 기존 라이트/다크·1280×720/실제 앱 창·하단 공간·접근성 이름과 최소 터치 영역을 검증한다.

정합성 검토: 헌장2.4.0과002 REC-007/008,004 PLAY-011/012,006 UX-010을 대조했다. 사용자 요청이 기존 다음2개·TTS 전체 재시작·최근4문장 표시를 대체한다. 실제 마이크 인식 정확도와 실차 허용을 합성 UI 결과로 주장하지 않는다. 데이터/동의/원본 보존·포커스 상실 중단은 유지한다.

## C048 — 연결/저장 알림과 간결한 공통 플레이어 (구현 전 계획)

2026-11-14. fillCarHome의 최신 기록 월+전체 개수 조합을 전체 기록 수로 교체한다. 기존 전체 목록/작성 중 진입과 날짜순 최신 카드 선택은 유지한다.

정합성 검토:003 SYNC-010,004 PLAY-015,006 UX-011을 대조했다. 단순 연결 등록과 전송 성공을 혼동하지 않도록 상세 오류를 보존한다. 원본 불변·동기화 제한·목업·주행/편집 보호를 유지한다. 실제 네트워크/실차 확인을 합성 UI 결과로 주장하지 않는다. 각 변경의 중복/실패/초기 상태·월 경계·두 테마를 검증한다.
