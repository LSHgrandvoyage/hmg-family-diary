# 차량 맥락·테마·설정·화면

상태: 웹/에뮬레이터 구현 / 실차 신호 검증 잔여. 정리일: 2026-11-13. 작업 브랜치: dev.
이번 문서는 사용자 승인에 따라 기존 구현·기록을 사후 분리했다. 구현 전에 작성된 명세라고 주장하지 않는다.
이전 식별자: FR-016, FR-017; C007, C008, C013, C014, C021, C024, C027~032. [전체 색인](../README.md), [이전 명세](../archive/2026-11-13-before-split/spec.md).

## 사용자 가치와 수용 시나리오

1. 테마 순환·재실행·설정 왕복 중 현재 입력/파형/재생이 유지된다. 모바일에는 자동 전환 선택지가 없다.
2. 차 별명/차량 기본값 변경 후 과거 기록의 차량·위치는 변하지 않으며 미지원 값은 추측하지 않는다.

## 현재 요구사항

- **UX-001**: 사용자가 제공한 차곡차곡 디자인의 탐색·타이포·색상 체계를 따른다. 차량 설정/녹음/일기에 공통 왼쪽 바를 사용한다.
- **UX-002**: 차량 테마는 자동/라이트/다크를 버튼 하나로 순환하고 자동의 현재 해석을 표시한다. 모바일은 라이트/다크 수동 전환만 제공한다. 테마 변경은 미디어와 편집 상태를 유지한다.
- **UX-003**: 연결 별칭과 차량 별명은 차 별명 하나로 수정·동기화한다. 이름 변경은 과거 일기의 차량 스냅샷을 바꾸지 않는다.
- **UX-004**: 조회 가능한 제조사·모델·연식은 빈 필드의 기본값으로 제안하고 사용자 수정은 보존한다. 미지원/거절/시간 초과는 수동 입력을 허용한다. 에뮬레이터 정보를 실제 차종으로 단정하지 않는다.
- **UX-005**: 녹음 시작 시 차량 정보와 그 시점 위치·관측 시각·품질/권한/출처를 스냅샷으로 보존한다. 위치가 없으면 기록은 허용하며 편집 시 위치로 대체하지 않는다. VIN/정밀 좌표를 일기 생성 입력에 새로 보내지 않는다.
- **UX-006**: 설정 왕복 시 이전 UI/편집 상태를 유지하고 모바일 패널 닫기는 우측 X로 통일한다. 초기 녹음 안내는 008, 주행 화면은 004가 담당한다.
