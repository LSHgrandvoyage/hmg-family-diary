# C030 차량 왼쪽 바 통일

2026-11-12. 설정/녹음/일기 화면에서 서로 다른 왼쪽 메뉴를 표시하던 문제를 공통 템플릿으로 수정했다. 녹음 중·일기 상세/검토도 같은 메뉴를 쓴다. 선택된 탭만 강조한다.

테마는 현재 모드 아이콘·이름을 표시하는 하나의 버튼으로 자동→라이트→다크→자동을 순환한다. 접근성 이름에는 현재 상태와 다음 상태를 표시한다. 자동 진입 시 시스템 기준과 실제 적용 색상을 안내하며, 수동 모드로 바꾸면 남아 있던 자동 안내를 제거한다. 설정 본문의 화면 모드 카드/조작은 제거했다. 모바일 수동 라이트/다크는 유지한다. 저장·SDK/서버 계약과 주차 권한은 기존 정책 그대로다.
