# C053 공개 GitHub 제출본 준비

2026-11-15. 소유 명세는 [007 DEP-005/010/011](../../specs/007-release-deployment/spec.md)이다. 사용자가 지원서·동의서 서명을 맡고 나머지 제출 준비를 요청했다. 숏폼 SNS 게시는 하지 않는다.

## 변경 범위

- 공개 저장소의 `apk/새벽개발팸_차곡차곡_release.apk`에 기존 검증 release0.2.13/code14를 포함한다. 파일 SHA256은 `35f04d789de885ad6e97a63a91a594dc410ca89352414cccdb89ef0d7b064863`이다.
- APK 빌드 기준 소스는 `5f62e010479f149762e58816d97cc2ef949f22a4`다. 이번 문서·포장 변경을 앱 재빌드로 표시하지 않는다. 공개 메타데이터에는 파일 해시와 공개 서명 인증서 지문만 있고 개인 서명 키는 없다.
- README·release 실행 안내·Windows 안내를 현재 UI/6자리 연결/contestRelease 중심으로 정리했다. GitHub 루트와 ZIP source, 초기 설치와 업데이트,18443과8443을 구분했다.
- ZIP 패키징은 공개 APK의 무결성·서명·버전과 빌드 기준 이후 APK 입력 소스의 동일성을 확인한다. manifest의 제출 소스 커밋과 APK 빌드 커밋을 분리했다. 새 플랫폼 검토와 아키텍처 문서도 소스 묶음에 포함한다.
- 개인 지원서·동의서·사진·녹음·DB·CA 개인 키·실제 환경 비밀은 Git/ZIP에 넣지 않는다. 바탕화면 화면 PDF와 컨셉 영상은 소스 공개와 분리한다.

## 검증 기록

- `scripts/check-specs.py`: 8개 기능 디렉터리의 필수 파일·문서 링크·요구사항/작업 매핑 통과.
- 수정한 Markdown의 로컬 링크42개 존재 확인, `git diff --check`, 패키징 스크립트 Python 문법 검사 통과.
- apksigner의 서명 검증과 공개 인증서 지문 대조, aapt의 패키지·라벨·0.2.13/code14·디버깅 비활성 확인 통과.
- APK 내 웹 자산146개가 현재 소스와 byte 단위로 일치한다. 앱/차량 및 차량 번들 웹 입력이 빌드 기준5f62e01 이후 바뀌지 않았음을 확인했다.
- 새로 게시할 기존21개 커밋의 변경232경로와 이번 변경에서 민감 경로/개인 키·주요 토큰 패턴 후보를 검사했다. 이는 개인정보/저작권 전체를 인증하는 검사가 아니다.
- 새 허용 목록으로 source-only ZIP을 생성해662개 소스 파일을 확인했다. APK는 별도 apk/에 한 번만 포함하고 소스 안에 중복하지 않는다.

C052의 앱 기능 시험을 이번 문서 작업에서 다시 실행했다고 주장하지 않는다. 공개 게시·최종 ZIP 검증 결과는 실제 수행 후 아래에 기록한다.

## 완료로 간주하지 않는 범위

플랫폼 원본 취득·보관·휴대폰 전송의 공식 지원/공모전 적합성, 최신 APK의 Windows 전체 재현, 실차·마켓 정책, 운영 환경은 별도다. 공개 문서 재검토 결과는 [플랫폼 검토](../contest/platform-review-2026-11-15.md)를 따른다.

서명된 최종 접수양식을 받기 전에는 실제 접수 메일을 보내지 않는다. 사용자 서명과 최종 발송/접수 확인은 개발 산출물 게시와 별도 상태다. 숏폼 SNS 게시도 하지 않는다.
