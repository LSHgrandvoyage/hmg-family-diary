# 원본 타임라인·TTS·주행 음성

상태: 에뮬레이터 구현 / 실차 정책 검증 잔여. 정리일: 2026-11-13. 작업 브랜치: dev.
이번 문서는 사용자 승인에 따라 기존 구현·기록을 사후 분리했다. 구현 전에 작성된 명세라고 주장하지 않는다.
이전 식별자: FR-001, FR-003, FR-009; C019, C020, C025, C026, C028, C032, C038. [전체 색인](../README.md), [이전 명세](../archive/2026-11-13-before-split/spec.md).

## 사용자 가치와 수용 시나리오

1. 같은 완성 일기로 TTS→원본→일시정지→TTS 전환 시 겹치는 재생과 자동 재개가 없다.
2. 주행 전환 시 편집/사진은 숨겨지고 진행 중 음성은 허용 범위에서 유지된다. UNKNOWN/중단/주차 복귀를 검증한다.

## 현재 요구사항

- **PLAY-001**: 양쪽 기기에서 전체 원본을 재생·일시정지·탐색하며 발언을 선택하면 그 구간부터 원본 끝까지 재생한다. 시각이 없는 이전 발언은 시간을 추정하지 않고 전체 재생을 제공한다.
- **PLAY-002**: 현재 발언·재생 위치·파형을 실제 재생 시간에 맞추고 진행 부분을 주황색으로 표시한다. 원본 내려받기는 모바일 음성 영역에서 제공하며 기기 미지원은 안내한다.
- **PLAY-003**: 차량의 완성 일기 TTS 목록은 정상 완료 때만 다음 일기로 넘어간다. 정지·오류·늦은 콜백·포커스 상실 후 자동 재개하지 않는다. 모바일 TTS는 현재 구현 범위가 아니다.
- **PLAY-004**: 주행 청취 화면에는 기본 일기 이어 듣기 한 플레이어만 표시한다. 원본 전환은 같은 일기를 유지한다. 재생 중 전환은 기존 엔진 종료 후 시작, 멈춘 상태 전환은 자동 재생하지 않는다.
- **PLAY-005**: 이전/재생/정지 또는 일시정지/다음은 접근성 이름을 가진 아이콘이다. TTS는 정지 후 해당 일기 처음부터, 원본은 일시정지 위치부터 재생한다. 정상 종료 설명은 숨기고 오류는 알린다.
- **PLAY-006**: 주행에서는 허용된 녹음·청취만, 주차에서는 본문·사진·검토를 제공한다. UNKNOWN/권한/동의 상실 시 중단하며 모의 입력을 실차 허용으로 간주하지 않는다.
- **PLAY-007**: 사용자가 시작한 녹음·청취는 서비스가 소유해 내비 화면에서도 유지한다. 오디오 포커스 정책을 지키고 캡처와 청취는 동시 시작하지 않는다. 미녹음 D→P 복귀는 녹음 홈이다.

- **PLAY-008**: 사용자가2026-11-13 Downloads에 제공한1280×720 PNG4개(주행 대기/녹음 중/녹음 멈춤/일기 듣기)를 주행 화면의 새 정본으로 한다. 왼쪽 메뉴를 제거하고 상단 로고·주행 상태, 큰 녹음/듣기 선택, 녹음 시간·실제 입력 파형과2개 조작 버튼을 제공한다. `이 순간 표시`는 제외한다. 주행 듣기는 현재 제목·날짜·순서와 다음2개 일기의 짧은 메타데이터만 허용하며 본문·사진·전체 인식문 탐색·검색은 계속 차단한다. 주행 녹음의 최신 인식문 표시는002 REC-007을 따른다. 일기 낭독/그날의 목소리 전환은 같은 기록을 유지하고 녹음 화면으로 돌아갈 때 재생을 종료한다. UI 전환은 녹음을 자동 시작하지 않는다.
- **PLAY-009**: 원본의 진행 막대/시간은 실제 재생 위치와 원본 길이에 연결한다. 현재 Pleos TTS3.3.1은 pause/seek/총길이/구간 위치 API가 없어 낭독은 시작 콜백 이후의 실제 경과시간과 `낭독 중` 상태를 표시하며 총길이·진행률을 추측하지 않는다. 낭독의 멈춤 아이콘은 엔진 정지이며 다시 누르면 현재 일기 처음부터 재생한다(PLAY-005 유지). 녹음 중에는 청취를 제공하지 않고 멈춘 파형은 회색 직선으로 고정한다.

- **PLAY-010**: D→P 전환 시 사용자가 시작한 TTS/원본 청취를 이어가며 차량 주차의 녹음·일기·설정 화면에 공통 재생바를 표시한다. 현재 제목/듣기 방식/실제 진행 상태와 TTS 정지, 원본 일시정지·재개, 종료를 제공한다. 재생 중 화면 탐색은 음성을 암묵적으로 종료하지 않으며 녹음 시작은 재생이 종료된 후에만 가능하다. 재생바가 내용·조작을 덮지 않는다. UNKNOWN/동의 상실은 기존 중단 정책을 유지한다.
