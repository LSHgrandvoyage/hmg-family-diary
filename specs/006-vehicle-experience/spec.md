# 차량 맥락·테마·설정·화면

상태: 웹/에뮬레이터 구현 / 실차 신호 검증 잔여. 정리일: 2026-11-13. 작업 브랜치: dev.
이번 문서는 사용자 승인에 따라 기존 구현·기록을 사후 분리했다. 구현 전에 작성된 명세라고 주장하지 않는다.
이전 식별자: FR-016, FR-017; C007, C008, C013, C014, C021, C024, C027~032. [전체 색인](../README.md), [이전 명세](../archive/2026-11-13-before-split/spec.md).

## 사용자 가치와 수용 시나리오

1. 테마 순환·재실행·설정 왕복 중 현재 입력/파형/재생이 유지된다. 모바일에는 자동 전환 선택지가 없다.
2. 차 별명/차량 기본값 변경 후 과거 기록의 차량·위치는 변하지 않으며 미지원 값은 추측하지 않는다.
3. 앱 실행 아이콘, 차량 왼쪽 메뉴, 모바일 보관함 상단에서 같은 차곡차곡 로고를 알아볼 수 있다. 라이트·다크와 좁은 휴대폰 화면에서도 로고와 메뉴가 잘리지 않는다.

## 현재 요구사항

- **UX-001**: 사용자가 제공한 차곡차곡 디자인의 탐색·타이포·색상 체계를 따른다. 차량 설정/녹음/일기에 공통 왼쪽 바를 사용한다.
- **UX-002**: 차량 테마는 자동/라이트/다크를 버튼 하나로 순환하고 자동의 현재 해석을 표시한다. 모바일은 라이트/다크 수동 전환만 제공한다. 테마 변경은 미디어와 편집 상태를 유지한다.
- **UX-003**: 연결 별칭과 차량 별명은 차 별명 하나로 수정·동기화한다. 이름 변경은 과거 일기의 차량 스냅샷을 바꾸지 않는다.
- **UX-004**: 조회 가능한 제조사·모델·연식은 빈 필드의 기본값으로 제안하고 사용자 수정은 보존한다. 미지원/거절/시간 초과는 수동 입력을 허용한다. 에뮬레이터 정보를 실제 차종으로 단정하지 않는다.
- **UX-005**: 녹음 시작 시 차량 정보와 그 시점 위치·관측 시각·품질/권한/출처를 스냅샷으로 보존한다. 위치가 없으면 기록은 허용하며 편집 시 위치로 대체하지 않는다. VIN/정밀 좌표를 일기 생성 입력에 새로 보내지 않는다.
- **UX-006**: 설정 왕복 시 이전 UI/편집 상태를 유지하고 모바일 패널 닫기는 우측 X로 통일한다. 초기 녹음 안내는 008, 주행 화면은 004가 담당한다.
- **UX-007**: 사용자가 제공한 `차곡차곡_로고.svg`의 모양·비율·색상을 유지한다. Android 실행 아이콘과 초기 안내에 적용하고 차량 주차 화면 공통 왼쪽 바의 '차곡' 글자를 로고로 교체한다. 모바일 보관함 상단에는 '차곡차곡' 왼쪽에 로고를 배치한다. Android 아이콘 마스크 안에서도 그림이 잘리지 않게 여백을 확보하며, 로고는 테마에 따라 반전하지 않는다. 단독 로고에는 앱 이름을 대체 텍스트로 제공하고 인접 앱 이름과 중복해서 읽히지 않게 한다. 녹음 알림·동의·미디어 동작은 바꾸지 않는다.

- **UX-008**: 모바일 모든 화면의 라이트/다크 전환은 원형 배경·테두리 없이 해/달 SVG만 표시한다.44px 터치 영역·키보드 포커스·접근성 이름·실제 테마 전환/유지를 보존한다. 차량 주차 화면의 자동/라이트/다크 제어는 유지하고 주행 전용 화면은004의 참조 디자인을 따른다.

- **UX-009**: 차량 WebView는1280×720을 최소 설계 기준으로 쓰되 실제 앱 창의 가로/세로비에 맞게 가용 영역을 채운다. 글자/아이콘 비율은 유지하고 고정 비율 중앙 정렬로 생긴 상하 여백을 없앤다. OS의 시스템 바/내비 영역은 침범하지 않는다. 모의 주행 전환은 별도 시험 UI이며 앱 조작과 겹치지 않게 둔다. 모바일 가족 패널의 중복 연결 차량 관리 버튼은 제거하고 차량 탭에서만 해당 흐름으로 진입한다.

- **UX-010**: 차량 주차 일기 목록의 `일기 N편 이어 듣기` 별도 버튼을 제거한다. 개별 일기의 듣기 진입과 PLAY-011 공통 플레이어를 이용한다. 재생바가 목록·기존 조작을 가리지 않는다.

- **UX-011**: 차량 녹음 홈의 지난 일기 머리는 월 표시 없이 `전체 기록 N개`로 표시한다. N은 조회한 전체 로컬 기록 수이며 작성 중도 포함한다. 가장 최근 기록의 월을 전체 개수와 결합하지 않는다.10·11·12월/연도 경계를 섞어도 같은 전체 기준이고 카드 날짜는 해당 기록의 실제 녹음 날짜다.
