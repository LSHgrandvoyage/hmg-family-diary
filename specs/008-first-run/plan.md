# 첫 사용 안내 구현 계획

ENTRY-001~006을 대상으로 한다. `MainActivity`의 기존 native gate를 전용 `WelcomePanel`로 교체한다. faithful 화면의 VehicleTheme 색상과 큰 버튼을 재사용하고 첫 안내에서는 이전 탐색 바/상태 텍스트를 숨긴다.

동의 입력은 안내 패널이 소유하고 시작 버튼을 누른 뒤 service 동의 상태에 반영한다. 초기 UNKNOWN의 시험 P 부여는 에뮬레이터 빌드·명시적 시작·미동의 서비스·시험 상태 없음 조건을 모두 확인한다. 기존 recording/playback service와 bridge 권한을 우회하지 않는다.

## 검증 계획

실제 Pleos 계측으로 사전 시작 차단, 동의→녹음 홈, P/D 왕복, 미녹음 복귀, UNKNOWN 재차단, 테마/포커스/크기를 확인한다. 처음 실행한 테스트 앱의 계정·자료를 임의 초기화하지 않는다. 라이트/다크 스크린샷을 시각 확인한다. 기존 단일 주행 플레이어와 회복 시험은 변경 영향에 맞춰 회귀한다.

## 헌장 확인

원본·가족 격리·실차 제한 유지. 시험 P는 알려진 실차 신호를 대체하지 않으며 주행 제한은 그대로다. 영구 동의나 자동 녹음은 추가하지 않는다.
