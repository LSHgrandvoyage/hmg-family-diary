# 첫 사용 안내와 진입

상태: 에뮬레이터 구현·검증 완료. Windows 새 버전/실차 검증은 미실행. 2026-11-13 사용자 요청. 작업 브랜치: dev. 변경 식별자 C039.
이번 새 화면은 아래 기준을 작성한 뒤 구현한다. 기존 전체 명세 분리는 C040 사후 정리 예외다.

## 사용자 가치

가족 기록의 보관·공유 범위를 이해하고 차곡차곡의 녹음 홈으로 바로 들어간다. 초기 화면에서 시험용 차량 상태를 고르지 않는다.

## 수용 시나리오

1. 새 프로세스에서 라이트/다크 첫 안내가 기존 제품 색상·큰 글자·버튼으로 표시되고 P/D/모의/차량 신호 체크박스가 없다.
2. 공동 녹음/보관 안내 확인 전에는 시작할 수 없다. 확인 후 시작하면 에뮬레이터 기본 주차 상태의 녹음 홈으로 이동하고 기존 시험 전환 버튼이 동작한다.
3. 실제로 알려진 주행 상태나 진행 중 서비스가 있으면 첫 진입이 임의로 P로 바꾸지 않는다. 진입 후 UNKNOWN은 미디어를 차단하고 자동 P 복구하지 않는다.
4. 동의를 철회하거나 확인하지 않고 나가면 녹음·재생이 시작되지 않는다. 앱이 다시 만들어져도 동의를 영구 자동 승인하지 않는다.

## 요구사항

- **ENTRY-001**: 첫 안내에서 모의 P/주행·차량 신호 선택 UI를 제거한다. 기존 앱 내 시험 전환 버튼과 주행 제한은 유지한다.
- **ENTRY-002**: 기존 VehicleTheme의 라이트/다크 색상·카드·타이포 체계를 사용한다. 시작/나중에 버튼과48dp 이상 조작 영역·키보드 포커스를 제공한다.
- **ENTRY-003**: 원본 목소리·인식문·일기 보관과 연결된 가족 보관함 자동 공유(차량/녹음 위치 포함)를 간단히 알린다. 공동 녹음 안내 체크는 명시적이며 사전 체크하지 않는다.
- **ENTRY-004**: 녹음 홈으로 들어가는 버튼은 서비스 준비와 안내 확인 후 활성화한다. 시작은 녹음을 자동 개시하지 않는다. 위치/서버 설정은 기존 설정 화면에서 접근한다.
- **ENTRY-005**: 에뮬레이터 한정 빌드에서 최초 안내 확인 시 신호가 UNKNOWN이고 시험 상태가 없을 때만 기본 시험 P를 설정한다. 이미 알려진 상태/녹음 서비스는 보존한다. 이후 UNKNOWN은 자동 정상화하지 않는다.
- **ENTRY-006**: 안내 상태에서도 기존 기록/미디어 bridge 접근은 차단한다. 동의 철회·서비스 연결 상실·UNKNOWN의 기존 중단 정책을 유지한다.

## 범위 밖

클라우드 배포·운영 인증서 변경·실차 모의 주차 허용·개인정보 법적 검토는 이번 작업이 아니다.
