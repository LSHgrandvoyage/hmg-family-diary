## 우리 팀의 준비 순서

- [X] 지원서 임시 PDF를 바탕화면 제출 폴더에 분리 보관. 소스+APK ZIP에는 넣지 않았다.
- [ ] 작성해 둔 1차 지원서에 “고정 목업 일기”와 플랫폼 미확인 범위를 정확히 반영한다.
- [ ] 전원 동의·서명·날짜·연락처를 확인한다. 개인 지원서/동의서는 공개 Git 저장소에 넣지 않는다.
- [ ] 권장: Windows 팀원이 [환경 안내](../team/windows-testing.md)로 새 환경에서 시험한다. 공식 필수 제출 조건과 구분한다.
- [ ] 선택 가산점: 합성 대화/테스트 사진으로 짧은 영상: 녹음 → 주차 검토 → 고정 목업 저장 → 자동 동기화 → 사진 → 원본/TTS 청취를 보여 준다. 목업·모의 주행 표시는 숨기지 않는다.
- [X] C035 에뮬레이터용 서명된 `contestRelease` 구현·설치/실행 검증 및 소스 패키징 경로 준비. [실행 안내](release-runbook.md).
- [ ] 제출 APK의 원본 취득/보관/전송에 대한 공개 지원 근거를 확정한다. 미확인이라는 고지만으로 공모전 적합성이 확보되지는 않는다. 근거가 없으면 공식 STT 기반 제출 범위 재설계를 검토한다. 실차/마켓 승인은 별도이며 1차에 실차 시연이 필요한 것은 아니다.
- [X] 사용자 결정: private 저장소 유지, 제출 커밋의 소스+release APK ZIP을 준비한다. 다운로드 링크 업로드와 접수는 아직 실행하지 않았다.
- [X] 제출 소스/APK 버전을 manifest와 파일 해시로 고정하는 패키징 준비. 현재 선택은0.2.6이며 정확한 제출 커밋은 최종 ZIP의 manifest.json에서 확인한다. 이전 동결본의 커밋을 메일에 재사용하지 않는다.
- [ ] 선택한 ZIP을 업로드하고 다른 PC의 비로그인 환경에서 다운로드·압축 해제·설치를 확인한다. 로컬 생성만으로 접수 완료가 아니다.
- [ ] 출품작의 권리·기수상 여부, 팀 참가 자격/인원 및 선정 후 PT·현장 참여 의무를 팀과 확인한다.
- [ ] 제목·수신·CC·첨부와 링크 접근을 최종 확인한 뒤 직접 발송한다.

## 접수 메일 초안

```text
제목: [차량용 앱 개발 공모전] 새벽개발팸_<대표자명>
수신: appdevchallenge@hyundai-partners.com
참조: <팀원 전원>

안녕하세요. 새벽개발팸의 차량용 가족 일기 앱 차곡차곡을 제출합니다.
첨부: 접수양식 및 참가자 전원 개인정보 동의서
소스+APK 압축 링크: <업로드 후 실제 내려받기 주소 입력>
소스 커밋: <최종 ZIP의 manifest.json에 기록된 source_commit>
제출용 APK: 압축 안 apk/새벽개발팸_차곡차곡_release.apk
실행 안내: 압축 최상위 README.md
시연 영상: <선택 — 제출하지 않으면 이 줄 삭제>

현재 일기 생성은 'AI 생성 일기 목업 입니다.'라는 고정 결과를 사용합니다.
에뮬레이터 시험 및 공식 SDK 사용 범위는 실행 안내에 구분했습니다.
감사합니다.
```

위 메일은 초안이다. 원본 음성 경로의 적합성 확인, 최종 지원서·동의서 교체와 링크 접근 확인을 마친 뒤 사용한다. APK 범위를 바꿨다면 소스 커밋·해시도 다시 고정한다.

바탕화면 `차곡차곡_공모전_제출/새벽개발팸_차곡차곡_제출용.zip`이 현재 동결한 묶음이다. 팀 테스트용 ZIP이나 `dist/contest` 검토 묶음과 구분한다. 개발자 계정·토큰·데이터 볼륨은 포함하지 않는다.

## 현재 제출 묶음

사용자 결정으로 바탕화면 제출 폴더에는 최신 최종 ZIP 하나만 둔다.0.2.6에는 주행 인식문·새 동의 화면·창 크기 대응·주차 공통 플레이어와 모바일 연결 단계 안내·테마 아이콘과4가지 새 주행 화면, 제공 로고 적용,6자리 연결, 원본 전송 복구, 단일 주행 플레이어, 첫 안내 화면과 기능별 명세가 포함된다. 이전 APK/업데이트 안내/임시 지원서는 제출 폴더 밖에 보관한다. 정확한 커밋·버전·해시는 ZIP의 manifest.json과 SHA256SUMS.txt가 정본이다.
