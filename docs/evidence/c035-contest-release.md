# C035 차곡차곡 제출용 release 검증

검증일: 2026-11-12. 팀명 새벽개발팸 / 앱명 차곡차곡. 공개 업로드·이메일 접수·마켓 승인을 수행한 기록이 아닙니다.

## 빌드와 구성

- variant: `contestRelease`, package: `io.hmg.familydiary.contest`, version: `0.2.0`(code1).
- `debuggable=false`, 전용 RSA3072 키 서명. apksigner v2 서명 검증 통과. 실제 앱의 FLAG_DEBUGGABLE이 꺼졌으며 adb run-as는 거부됩니다.
- 기존 probeDebug와 별도로 설치합니다. 에뮬레이터 하드웨어 제한은 유지하고 디버그 여부와 명시적인 에뮬레이터 시험 권한을 분리했습니다. 실차·마켓 허용을 우회하는 DO 선언을 추가하지 않았습니다.
- 목업 생성은 앱 내부에서 `AI 생성 일기 목업 입니다.`를 반환합니다. 별도 목업 서버, 개발자 토큰, 실제 AI 호출, adb reverse4319가 필요하지 않습니다.
- 서버 설정은 HTTPS 주소와 공개 CA만 가져옵니다. 현재 Pleos 활성 사용자에서 표준 파일 선택기 처리기가 없는 것을 확인해 JSON 붙여넣기와 CLI의 명시적 Intent 전달을 추가했습니다. 전달만으로 적용하지 않으며 앱에서 주소·CA 지문 확인 후 저장합니다.

## 실제 실행 확인

Mac ARM64, Pleos Connect2.1.0 / API34 ARM64, Android Emulator37.2.13. 물리 화면2560×1440, 참조 UI1280×720. 시험용 에뮬레이터는 호스트 마이크를 끄고 CPU2개/메모리2GB로 실행했습니다. 사용자 실제 음성·사진은 사용하지 않았습니다.

1. 새 contest APK 설치 및 첫 화면 실행, 설정 확인창 표시와 사용자 적용을 확인했습니다. 공개 서버 설정은 run-as 없이 전달했습니다.
2. 비디버그 release에 같은 키로 서명한 계측 APK를 연결해 실제 녹음 시작/종료와 WAV 보관을 검증했습니다. 이 녹음은 마이크 입력이 꺼진 무음이며 음성 정확도 검증과 구분합니다.
3. 별도 합성 음성 fixture를 공식 ON_DEVICE STT에 입력해 최종 텍스트를 받았습니다. 이전에 관찰된 단어 단위 오인식을 이번 검사로 해결했다고 주장하지 않습니다.
4. 확인문 → 앱 내 고정 목업 → 검토/저장 → 원본 재생 진행 → 공식 TTS 시작·종료를 검증했습니다. 확인문과 원본 SHA-256이 보존됩니다.
5. 모의 주행 상태에서 일기 읽기·서버 설정을 차단하고 주차 복귀 후 설정 동작을 확인했습니다. 실차 주행 검증은 아닙니다.
6. 별도 `hmg-family-diary-team` 프로젝트의 합성 계정과 release 앱을 연결했습니다. 완성 일기가 자동 업로드되고, 보호자 HTTPS API에서 같은 텍스트·고정 목업·원본 SHA-256을 확인했습니다. 테스트 기록과 기기 연결은 서버에서 삭제/폐기했습니다.
7. 잘못된 설정 형식·32KB 초과·HTTP·userinfo/path/fragment 주소·불필요한 비밀 필드를 거부합니다. 연결된 보관함의 CA 교체는 거부하고 같은 CA의 주소 변경은 허용하는 검사를 통과했습니다. 입력 수정 후 오래된 목업 채택 거부와 취소 후 callback 차단도 확인했습니다.

최종 APK로 계측 검사2개가23.401초에 통과했습니다. APK SHA-256은 `0d26a45f2334ac97f9d206c44e8b2783b5e261cb2b574de813fd031a3e88ea54`입니다. 첫 실행은 검사 스크린샷의 외부 저장 경로가 없는 문제로 실패했으며 앱 캐시 경로로 변경 후 재검사했습니다. 최종 UI 반영 후 재검사는 이전 폐기 계정의 로컬 기록이 남은 상태에서 새 가족 계정을 만들어 자동 동기화 대기 검사가 실패했습니다. 신규 설치 검사는 별도 contest 앱의 합성 데이터만 초기화한 환경에서 실행하도록 전제 조건을 명시했습니다. 다른 가족으로 자동 전송하지 않는 기존 보호 로직은 변경하지 않았습니다.

## 회귀 및 화면 검증

- Android 단위 검사23개, TypeScript/Vitest111개, TypeScript 타입 검사 통과.
- 독립 headless 브라우저의 합성 bridge로 release 전용 설정 버튼 노출, 기존 개발 환경에서 숨김, 명령 전달, 48px 이상 터치 영역, 라이트/다크 및 가로 넘침 부재를 확인했습니다.
- 설정 버튼을 기존 연결 버튼 옆에 배치해720px 화면에서 카드가 잘리지 않게 했고 두 테마 화면을 시각 확인했습니다. 해당 이미지는 합성 UI입니다.
- 소스 ZIP에는 SDK/AVD·빌드 캐시·환경 파일(예시 제외)·인증서 개인 키·DB·개인 미디어를 넣지 않습니다. 제출 manifest에 소스 커밋과 최종 APK SHA-256을 기록합니다.

## 공개 자료와 남은 확인

- Windows 실제 호스트/Pleos 이미지/마이크, iPhone Safari 실기기 전체 재검증, 실차 장치/주행/내비 포커스 혼합, 마켓 심사는 이번 검사 범위 밖입니다.
- 차량 마이크 원본 취득·보관·휴대폰 전송의 전체 공식 허용은 아직 확인되지 않았습니다. 서명된 release가 이를 승인받았다는 의미는 아닙니다.
- 자동 화자 식별, 실제 자동차 화자 LLM, 공개 클라우드 운영, 운영 SMTP, 암호화 백업/복구는 완료 기능이 아닙니다.
- 원본 취득 관련 공개 근거와 제한은 `docs/contest/platform-review-2026-11-12.md`, 제출 실행 방법은 `docs/contest/release-runbook.md`에 있습니다. 제출 묶음에서는 `source/` 아래 같은 경로를 사용합니다.
- 검증용 에뮬레이터와 팀 컨테이너를 종료했습니다. 이번에 만든 contest 앱의 합성 데이터와 계측 APK도 정리했고, release 앱 설치는 남겼습니다. 기존 사용자 probe 개발 앱과 개발 컨테이너는 유지했습니다.

서명 키와 비밀번호는 개발자 로컬 `.tools/signing/`에 보관합니다. 제출물에는 포함하지 않습니다. 후속 APK 업데이트에 같은 키가 필요하므로 이 비공개 디렉터리는 별도로 안전하게 보관해야 합니다.
