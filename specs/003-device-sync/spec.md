# 가족 연결·자동 동기화·삭제

상태: 로컬 HTTPS 구현 / 사용자 실제 실패 파일 복구 확인 잔여. 정리일: 2026-11-13. 작업 브랜치: dev.
이번 문서는 사용자 승인에 따라 기존 구현·기록을 사후 분리했다. 구현 전에 작성된 명세라고 주장하지 않는다.
이전 식별자: FR-007, FR-008, FR-010~012; C001~006, C020, C023, C037, C038. [전체 색인](../README.md), [이전 명세](../archive/2026-11-13-before-split/spec.md).

## 사용자 가치와 수용 시나리오

1. 차량에서 최종 저장한 기록이 휴대폰에 나타나고 같은 원본 해시로 재생된다. 오프라인 저장 후 재연결해도 중복되지 않는다.
2. 사진을 휴대폰에서 추가하면 차량 주차·유휴 시 반영된다. 삭제/만료/보관함 변경 시 기록이 부활하거나 다른 가족에게 게시되지 않는다.
3. 2.002초 합성 원본과 기존 차단 작업이 재시도되며 본문 충돌은 그대로 보호된다.

## 현재 요구사항

- **SYNC-001**: 보호자 인증과 가족 보관함 권한을 검증한다. 현재 DB는 보관함당 활성 차량 1대다. 다중 활성 차량을 구현했다고 표시하지 않는다.
- **SYNC-002**: 연결 코드는 숫자6자리·5분·일회용이며 선행0을 보존한다. 모바일은6개 칸에 숫자1개씩 표시한다. 기존 연결을 유지하고 이전8자리 미사용 코드는 새로 발급한다. 최신 이미지 반영과 서버 설정 실행은007 DEP-007에서 검증한다.
- **SYNC-003**: 완성 일기는 별도 공유 조작 없이 영속 outbox로 본문과 원본을 멱등 전송한다. 작성 중은 전송하지 않는다. 최초 연결 전 완성 기록을 이관하되 다른 보관함의 자료는 자동 게시하지 않는다.
- **SYNC-004**: 변경 알림 SSE와 cursor 변경분 조회를 결합한다. 재접속/전면 복귀 시 누락분을 받으며 느린 정기 폴링은 쓰지 않는다. 전송 재시도와 SSE 재연결은 허용한다.
- **SYNC-005**: 차량의 수신 적용은 주차·유휴 상태에서 한다. 녹음·청취·편집 중인 기록을 덮어쓰지 않는다. 완료 표시는 해당 기기와 서버 일치이며 모든 오프라인 기기 반영을 보장하지 않는다.
- **SYNC-006**: WAV 길이는 정수 바이트 기반으로 계산하고 해시/포맷 불일치를 거절한다. 기존 audio 검증 실패를 제한적으로 재시도한다. 충돌·삭제 작업을 임의 해제하지 않는다.
- **SYNC-007**: 서버 원본 대기 중에도 동일 해시의 로컬 원본을 가진 차량은 사진을 수신한다. 신규 수신 기기는 준비되지 않은 원본을 완료로 표시하지 않는다.
- **SYNC-008**: 삭제는 원본·텍스트·사진과 기기 사본에 적용하며 tombstone을 먼저 반영한다. 연결 해제/토큰 만료/타 보관함 접근을 차단한다. 전송 오류·재시도·인증 재연결 이유를 표시한다.

- **SYNC-009**: 모바일 보관함의 차량 표시에는 활성 연결이 있을 때 `연결됨`을 표시하며 기록 존재 여부를 연결의 근거로 삼지 않는다. 연결 화면은 코드 만들기→차량에 입력→연결 확인의 실제 단계를 안내한다. 연결 완료 후6칸 코드를 숨기고 연결된 차 별명·완료 상태·차량 관리를 제공한다. `보관함으로` 버튼은 제거하고 상단 뒤로가기를 유지한다. 코드 발급/만료/재발급 중에는 실제 진행 단계를 표시하고 기존 일회용/5분 계약을 유지한다.
