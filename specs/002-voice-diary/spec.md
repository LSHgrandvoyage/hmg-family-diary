# 음성 기록·STT·일기 생성

상태: 에뮬레이터 구현 / 생성은 고정 목업. 정리일: 2026-11-13. 작업 브랜치: dev.
이번 문서는 사용자 승인에 따라 기존 구현·기록을 사후 분리했다. 구현 전에 작성된 명세라고 주장하지 않는다.
이전 식별자: FR-002~006, FR-013~015; C016, C021, C033. [전체 색인](../README.md), [이전 명세](../archive/2026-11-13-before-split/spec.md).

## 사용자 가치와 수용 시나리오

1. 주차에서 여러 주제와 정정이 섞인 대화를 녹음하면 원본과 인식문이 남고, 문장 수정 후 고정 목업을 검토·저장할 수 있다.
2. 인식 실패/생성 취소/오래된 revision 응답에도 원본은 보존되고 완료로 잘못 표시하지 않는다.

## 현재 요구사항

- **REC-001**: 자유로운 대화를 사용자가 시작·종료하고 같은 PCM으로 원본 WAV와 실시간 STT를 만든다. 입력 길이·장소·주제를 강제하지 않는다.
- **REC-002**: 녹음 파형·시간은 실제 입력을 반영한다. 주차에서만 인식 중 텍스트와 종료 후 문장 수정을 제공한다.
- **REC-003**: 원본·원래 인식문·수정문·revision·발언 구간을 연결하며 문장 수정으로 원본을 바꾸지 않는다. 실패·빈 인식 결과에서 다시 인식을 제공한다.
- **REC-004**: 현재 제출 앱의 새 생성 본문은 정확히 `AI 생성 일기 목업 입니다.`다. generation_mode=mock과 입력 revision/원본 참조를 보존한다. 외부 AI API를 호출하지 않는다.
- **REC-005**: 생성→미리보기→최종 저장을 차량에서 완료한다. 생성/취소/늦은 응답이 다른 입력을 덮어쓰지 않는다. 자동 동기화는 최종 저장 이후다.
- **REC-006**: 자동 화자 식별을 제공한다고 표시하지 않는다. 사용자가 지정한 화자와 STT 구간만 보존한다. 사건·시점·장소 분류, 자동차 화자 LLM, 그룹 재편집은 후속 목표다.
