# C050 차량 상호작용·처리 상태 개선

2026-11-14. REC-010, SYNC-011, PLAY-016, UX-012, DEP-009의 수용 조건 → 계획·정합성 검토 → 작업 정의 후 구현했다. 관련 명세는 [음성 기록](../../specs/002-voice-diary/spec.md), [동기화](../../specs/003-device-sync/spec.md), [청취](../../specs/004-memory-playback/spec.md), [차량 화면](../../specs/006-vehicle-experience/spec.md), [실행·배포](../../specs/007-release-deployment/spec.md)다.

## 변경 결과

- 차량 홈·주행 화면·모바일의 연결 배지는 같은 `accent-soft` 배경과 `accent` 글자색을 쓴다. 휴대폰 SVG와 `연결 중`을 표시하며 주행 청취 화면에서도 유지한다. 연결 등록 표시이며 네트워크 접속·전체 업로드 완료를 보증하는 표시는 아니다.
- `Check failed.`는 Kotlin의 설명 없는 상태 검사 실패 문구다. 재생 진입의 녹음/STT·저장·동기화 경합, TTS 전환 대기에서 이 기본 문구가 노출될 수 있었다. 상태별 안내, 사용할 수 없는 목록/제어 비활성화, 처리 중 중복 요청 방지를 추가했다. 명시적 종료는 준비·동기화 대기 중에도 가능하다. 완성 일기가 없는 원본도 공통 플레이어에서 일시정지할 수 있다. 사용자가 겪은 여러 사례의 원본 로그는 없으므로 모두 같은 원인이었다거나 전부 재현했다고 주장하지 않는다.
- WebView 기본 터치 하이라이트를 제거하고 눌림 피드백과 `focus-visible`을 유지했다. 키보드/물리 조작의 포커스는 계속 보인다.
- P/D 전환 시 새 화면에만 220ms 슬라이드·페이드를 적용한다. 기존 주차 본문·사진 DOM은 즉시 제거하며 잔상 복제는 없다. 상태 갱신마다 애니메이션을 재시작하지 않으며 빠른 재전환은 이전 애니메이션을 취소한다. 모션 줄이기를 따른다.
- 서버 설정 intent 수신 후 일반 재활성화가 과거 녹음 때문에 검토 화면으로 이동하던 경로를 제거했다. 적용 후 설정 탭을 유지하고, 새 녹음 결과 callback의 검토 이동은 유지했다. CA 확인·명시적 적용·기존 연결 신뢰 경계는 유지한다.
- 주행 중 녹음 마치기를 누른 순간부터 원본/STT 마무리 화면과 로딩 표시를 제공한다. 추정 퍼센트 없이 실제 처리 상태를 따르고 끝나면 대기 화면으로 복귀한다. 종료 중 새 녹음·청취 버튼은 노출하지 않는다.
- 주행 목록의 날짜는 연도와 `MM.dd`를 함께 표시한다. 전체 날짜·제목 접근성 이름, 최근순 목록, 현재 일기 고정, 앞뒤8개/추가8개 조회는 유지한다.

## 전달 상태와 범위

Pleos 에뮬레이터 사용자10에서 `InteractionDeviceTest`, `DrivingListenDeviceTest`, `WelcomeDeviceTest`의 각 최종 실행이 통과했다. cache-only 합성 WAV/일기로 실제 원본 재생·일시정지/복귀, 실제 TTS·반복/종료, 설정 intent 적용·취소 후 화면 유지, 기존 녹음/새 결과 구분, 동기화 대기 시 구체적인 안내와 명시적 종료를 확인했다. 사용자의 원본 음성을 시험 자료로 사용하지 않았다.

서명 contestRelease **0.2.11 / versionCode12**, 패키지 `io.hmg.familydiary.contest`. APK SHA256: `bfc67dfab97a71914b94d8dd3c1f121d48bd1b2ca48811834949607366feb7c8`. APK의 변경 UI6파일은 소스와 byte 단위로 일치한다. 기존 데이터·연결을 유지한 덮어 설치를 완료했다.

기존 `.env.runtime`과 서버 주소·CA·DB/미디어 볼륨을 유지하여 Compose를 재빌드했다. web/DB healthy, worker/proxy 실행을 확인했고 실제 HTTPS가 제공하는 변경 UI6파일도 소스와 일치한다. 설정 테스트는 기존 주소·CA와 같은 값만 적용했으며 앱 기록·연결을 초기화하지 않았다.

화면 검증은 합성 자료다: [청취 라이트](connected-ui/c050-listening-light.png) · [청취 다크](connected-ui/c050-listening-dark.png) · [마무리 라이트](connected-ui/c050-processing-light.png) · [마무리 다크](connected-ui/c050-processing-dark.png).
