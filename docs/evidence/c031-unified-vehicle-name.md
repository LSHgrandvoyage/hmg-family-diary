# C031 차 별명 단일화

2026-11-12. 연결 별칭과 차량 정보의 차 별명을 하나의 현재 이름으로 통합했다. 차량에서는 설정의 우리 차 정보에서 수정하고, 연결 패널은 같은 이름을 표시한다. 휴대폰 연결 차량 관리도 차 별명이라는 명칭을 쓴다.

## 동작과 보존

- 최초 설정 접근 시 기존 차량 별명을 우선 이행한다. 비어 있으면 연결 이름, 모델, 우리 차 순으로 채운다. 이름은1~40자이며 기존 초과 이름은 임의로 자르지 않는다.
- 차량 변경은 로컬 pending 상태에 저장하고 기존 업로드 작업으로 전송/재시도한다. 대기 중임을 설정에서 표시한다. 별도 느린 조회 폴링은 추가하지 않았다.
- 휴대폰 변경은 서버 기기 이름 갱신과 SSE 알림을 통해 차량으로 전달한다. 차량 변경도 열려 있는 휴대폰 연결 화면에 반영한다.
- 과거 일기의 차량 스냅샷은 바꾸지 않는다. 현재 프로필을 바꾼 후 시작하는 기록에서 새 별명을 사용한다.

## 실행 검증

독립 headless Chrome의 `test-c029-ui.ts`로 중복 연결 이름 입력 제거, 단일 차량 편집기,40자 제한, 실패 후 입력 보존, 연결 시 프로필 이름 사용과 기존 테마/설정 화면을 검증했다. 이 화면 검사의 native bridge는 합성 응답이다.

`test-c031-name-runtime.ts`는 별도 QA 계정과 `name-sync-qa` 전용 디렉터리의 합성 무음 WAV/일기를 사용한다. 실제 HTTPS 서버와 에뮬레이터 계측3개가 통과했다.

1. 구형 연결 상태의 별명 이행, 연결 실패 시 pending 보존, CloudSync 객체 재생성 후 최신 이름 재전송,40자 초과 거부.
2. 휴대폰에서 차 별명 변경 후 차량의 실제 SSE 수신 및 현재 이름 갱신.
3. 차량 이름 변경 후 새로고침 없이 열려 있는 휴대폰 연결 화면 갱신.

변경 전후 합성 일기의 차량 별명이 차량 로컬과 서버 모두 유지됨을 확인했다. 테스트 후 생성한 일기를 삭제하고 테스트 연결을 해제했다. `connected-ui/c031-phone-name.png`는 이 합성 계정 화면이며 시각 확인했다. 재시작 검증은 동기화 클라이언트 객체를 재생성하여 디스크 상태를 다시 읽는 범위이며 OS 강제 종료 검증과 구분한다.

실제 WebView `NavigationAppearanceDeviceTest`1개도 통과했다(5.099초). 차 별명 저장, 과거 로컬 context 보존, 설정 왕복/테마 순환/주행 중 설정 차단 및 합성 PCM 파형 회귀를 검사했다. 실제 마이크는 사용하지 않았다.

## 빌드와 적용

TypeScript 검사, ProbeDebug/AndroidTest 빌드 및 ProbeDebug 단위 테스트 통과. APK SHA256: `76f110fc8364f85a391a1d39dc107ef043a955c16b944bacb2efa994094cf8e8`. APK의 app.js/settings.js와 현재 소스 일치를 확인했다. 최신 APK를 기존 AVD에 설치했고 개발 Docker 서버를 재빌드/적용했다. 실행 중 변경된 맥북 IP를 갱신했다. 검증용으로 시작한 화면 없는2코어/2048MB 에뮬레이터는 검증 후 종료했다. 사용자 기록·저장 볼륨은 유지하며 합성 테스트는 실차/Safari 실기기 검증을 대신하지 않는다. 외부 AI 호출은 없다.
