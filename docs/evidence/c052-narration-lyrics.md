# C052 가사형 낭독 문장

2026-11-14. 사용자 요청에 따라 [004 PLAY-009/017/018](../../specs/004-memory-playback/spec.md), [006 UX-014](../../specs/006-vehicle-experience/spec.md), 헌장2.5.0과 제품 정의를 구현 전에 갱신했다. 현재 문장 주변만 표시하는 에뮬레이터 범위 변경이며 실차·마켓 허용을 입증하지 않는다.

## 변경

- 주행 일기 읽어주기의 숫자 문장 수와 문장 진행바를 가사형 문장 영역으로 대체했다. 실제 경과시간은 유지한다. 기존 제목·날짜·목록·원본 재생과 아이콘 조작은 유지한다.
- 실제 Pleos TTS `onStart`에서 표시 문장을 확정한다. 이전 문장이 끝나고 다음 문장을 준비하는 동안 임의로 다음 문장을 읽는 것으로 표시하지 않는다. 현재 문장과 앞뒤 각2문장만 native bridge로 전달하며 전체 본문을 웹에 보내고 숨기는 방식이 아니다.
- 현재 문장은 세로 중앙에서 선명하게, 앞뒤 문장은 거리에 따라 낮은 강조로 표시한다. 문장 경계에서 위치·투명도를320ms 전환한다. 범위를 벗어난 DOM은 제거해 최대5개를 유지한다.250ms 시간 갱신·일시정지는 애니메이션을 반복하지 않으며 키보드 포커스를 빼앗지 않는다.
- 주변 문장은 한 줄 미리보기, 현재 문장은 줄바꿈하여 전체를 표시한다. SDK의 최대240 code point 구간도 읽을 수 있도록 문장 영역과 글자 크기를 조정한다. 임의 스크롤·문장 클릭 탐색은 없다. 모션 줄이기에서는 즉시 읽을 수 있는 최종 상태를 표시한다.
- 일시정지/재개는 같은 문장을 유지하고 자연 완료는 마지막 문장을 유지한다. 다른 일기·원본 전환·명시적 종료·오류는 이전 문장을 제거한다. 반복은 새 회차의 첫 실제 시작 문장으로 이동한다. UNKNOWN에서는 기존 오디오 접근 제한을 유지하며 문장 배열을 반환하지 않는다.
