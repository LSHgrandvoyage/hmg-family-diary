# C032 주행 화면 복구와 주차 홈 복귀

2026-11-12. 사용자 제공 `Downloads/차량 · 녹음 중@1x.png`를 시각 확인했다. 주행 진입 때 WebView를 숨기고 과거 네이티브 시험 패널을 표시하던 분기를 제거하고, 같은 녹음 템플릿의 메뉴·타이머·파형·하단 제어 배치를 사용하는 주행 화면으로 교체했다. 기존 음성 제어 핸들러는 유지하며 공개 bridge에서도 주행/음성 권한과 활성화 조건을 검사한다.

## 변경

- 시험 모드 전환 버튼은 디버그 에뮬레이터의 음성 기능 허용 상태에서 표시한다. 서비스 simulation이 null인 P 진입도 포함하며 화면 최상위에 배치한다. 실차 신호를 덮어쓰는 기능으로 확장하지 않았다.
- 주행 화면은 원본 디자인과 같은 배치이며 주행 중 인식문 대신 주차 후 확인 안내를 표시한다. 녹음하지 않을 때는 기존 원본/TTS 청취 제어를 제공한다. 녹음 중에는 녹음 제어에 집중하며 파형은 실제 입력 레벨 상태를 받는다.
- 주행 중 list/read/설정/사진과 본문 검토 권한은 계속 차단한다. 주행 진입 시 기존 검토 DOM·다이얼로그를 제거하고 미저장 검토 입력은 기존 방식으로 보존한다.
- 청취용 selected와 새 녹음의 pendingCaptureReview를 분리했다. 녹음 없이 주행→주차를 바꾸면 녹음 홈으로 돌아온다. 녹음 중이면 녹음 화면, 새 원본 저장 후 검토 대기면 해당 확인 화면을 연다. 검토를 끝내고 홈·목록·완성 일기로 이동하면 검토 대기를 해제한다.

## 검증과 범위

`test-c032-ui.ts`: 독립 headless Chrome/합성 native bridge. 초기 D 진입, 라이트/다크, 원본 참조 배치, 녹음/일시정지/종료, PCM 상태 파형, 인식문 미표시와 주차 홈 복귀 통과. `connected-ui/c032-driving-{idle,recording}-{light,dark}.png`를 생성하고 라이트/다크 화면을 시각 확인했다.

`NavigationAppearanceDeviceTest`: 실제 설치 APK/WebView 계측1개 통과(6.302초). P+동의 경로의 시험 버튼 노출, 동의+D 경로, WebView 주행 화면 노출과 구형 패널 숨김, 주행 중 읽기/설정 차단, 과거 selected가 있어도 미녹음 시 홈 복귀, 별도 합성 검토 대기가 있으면 확인 화면으로 복귀, 기존 설정/테마/합성 PCM 파형 회귀를 확인했다. 새 검토 대기는 합성 상태 주입으로 검사했으며 이번 검증에서 실제 마이크 녹음이나 실차를 시험하지 않았다.

`test-c029-ui.ts` 기존 설정·통합 차 별명·공통 메뉴/테마·모바일 회귀 통과. TypeScript 및 JS 구문 검사, ProbeDebug/AndroidTest 빌드와 단위 테스트 통과. 기존 `DrivingModeDeviceTest`의 화면 기대값도 새 WebView와 미녹음 홈 복귀에 맞췄지만 해당 실제 AudioRecord 테스트 전체는 이번에 실행하지 않았다.
