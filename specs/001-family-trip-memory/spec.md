# 차곡차곡 — 제품 공통 기준선

상태: 에뮬레이터·로컬 서버 프로토타입 구현, 실제 AI·실차/마켓 승인·운영 클라우드 미완료.
정리일: 2026-11-13. 작업 브랜치: dev. [기능 정본 색인](../README.md).

## 사용자 가치

가족이 차 안에서 자유롭게 나눈 이야기를 원본 목소리와 일기로 남기고, 차량과 휴대폰 양쪽에서 다시 듣고 본다.
자동차가 가족의 추억을 이야기하는 LLM 일기는 목표이며, 현재 생성 본문은 고정 목업이다.
초기 가족 타깃과 사용자 가치 검증은 가설이고 실제 사용자 연구 완료로 표시하지 않는다.

## 공통 요구사항

- **BASE-001**: 한마디/장소별 입력을 강제하지 않고 사용자가 시작한 자유 발화를 기록한다.
- **BASE-002**: 원본·인식문·수정문·일기 revision을 연결하고 편집으로 원본을 바꾸지 않는다.
- **BASE-003**: 같은 가족 보관함 권한과 삭제 경계를 양쪽 기기에 적용한다. 현재 활성 차량은 보관함당1대이며 차를 바꿔도 서버의 과거 기록은 보존한다.
- **BASE-004**: 주차 검토와 허용된 주행 음성을 구분한다. UNKNOWN은 차단하며 시험 상태를 실차 근거로 쓰지 않는다.
- **BASE-005**: 사진은 사용자가 추가하고 차량/녹음 시작 위치는 당시 스냅샷이다. 자동 화자 식별·영상·사진 자동 수집은 현재 범위가 아니다.
- **BASE-006**: 목업/구현/검증/미검증을 구분한다. 사용자 원본·정밀 위치·토큰을 Git·검증 자료에 넣지 않는다.

## 전체 수용 시나리오

1. 차량에서 안내 확인→녹음→인식문 수정→목업 검토→최종 저장을 완료한다.
2. 연결된 휴대폰에 본문과 동일 원본이 자동 전송되고, 추가한 사진이 차량 주차·유휴 때 반영된다.
3. 차량과 휴대폰에서 지난 기록을 찾고 원본을 듣는다. 차량은 TTS 목록과 주행 최소 조작을 제공한다.
4. 중단/오프라인/삭제/보관함 변경에서 원본·권한·삭제 상태를 보존한다.

## 소유권과 후속

세부 기준은 002~008의 기능 명세가 정본이다. 이 파일에 기능 변경 로그를 추가하지 않는다.
고객 성공 지표(5가족 중4가족 등)는 [기존 가설](../archive/2026-11-13-before-split/spec.md)에 보존하며 성과로 주장하지 않는다.
클라우드 이전은007의 계획, 실제 AI는002의 후속이다. 공통 계약 경로는 호환성을 위해 이 디렉터리에 유지한다.
