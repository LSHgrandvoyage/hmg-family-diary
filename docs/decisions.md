# 제품 결정 이력

## 2026-11-08 — SDD와 첫 제품 범위

- 사용자 요청: GitHub spec-kit으로 SDD를 적용하고 GitHub 저장소를 만든다.
- 추가 지시: 구현에 앞서 타깃·해결할 문제·베스트 시나리오를 정한다.
- 사용자 결정: 시간이 지나 다시 일기를 읽을 때 STT에 사용했던 원본 녹음도 재생한다.
- 사용자 결정: 차량과 휴대폰 양쪽의 다시 보기·듣기를 첫 버전에 포함한다.
- 작업 기준: 초등학생 자녀가 있는 자동차 나들이 가족, 기록을 주도하는 부모,
  방문 후 주차된 차에서 구성원별 짧은 발화. 이 세부 타깃은 검증할 가설이다.
- 범위 변경: 기존 기획의 원본 음성 보관 제외·기기 동기화 후속 항목을 폐기한다.
- 개발 영향: 음성 입력과 원본 보관의 연결, 보호자 보관함·기기 연결,
  동기화·재생·접근 제한·삭제를 첫 명세에 포함한다.
- 현재 단계: 제품 정의·헌장·기능 명세. 기술 스택 확정·앱 구현은 아직 수행하지 않는다.

## 2026-11-08 — 자유 발화와 LLM 분류·정제

- 사용자 수정: 차에 타서 오늘 일을 짧게 말하는 형식에 제한하지 않는다.
  이것저것 이야기하면 분류와 정제는 LLM이 맡는다.
- 폐기: 한마디·20~30초 권장 발화, 한 장소를 입력 단위로 고정, 발화별 사전 확인 흐름.
- 현재: 여러 장소·사건·시점·정정이 섞인 세션을 입력받고 사건별 초안을 묶음 검토한다.
- 유지: 가족 중심 초기 타깃, 명시적인 녹음, 주차 사용, 수동 발화자 선택,
  원본 음성 보관, 양쪽 기기 재생. 자동 화자 식별·상시 녹음은 추가하지 않는다.
- 보존: 정리에서 생략한 말도 원본에 남기고 관련 음성 구간으로 이동할 수 있게 한다.
- 측정 변경: 전체 발화 시간을 줄이는 대신 사전 분류 없이 완료하는지와
  발화 종료 후 사용자의 정리·검토 조작 시간을 본다. 생성 대기는 별도로 보고한다.
- 헌장: 원칙 VI 추가로 1.1.0. 아직 모델 실행·긴 음성 처리 검증을 수행하지 않았다.

## 2026-11-08 — 구현 계획과 작업 목록

- 다음 단계 요청에 따라 plan·research·data-model·contracts·quickstart·38개 tasks를 작성했다.
- 차량은 Kotlin Android, 휴대폰은 Next.js 모바일 웹으로 계획한다. 첫 범위의 읽기·듣기를 모두 유지한다.
- 보관은 Supabase Auth/Postgres/private Storage, 생성은 별도 작업자의 구조화 출력으로 계획한다.
- OpenAI Responses 초기 평가 후보는 gpt-5.6-terra이며 실제 계정 접근·품질·비용은 미검증이다.
- 차량 원본 녹음·검증된 주차 상태는 실제 G0~G2 통과 조건이다. 원본 캡처 경로를 확인하지 못했다고
  텍스트 전용으로 범위를 축소하지 않는다.
- 앱 코드·실제 SDK 실행·유료 자원 생성·배포는 이 단계에서 수행하지 않았다.
