# 웹 미리 보기 UI 개선 — 2026-11-08

사용자 요청: yeoul9703가 기여한 k-style-ui-ux를 적용하여 기존 화면을 개선한다.

## 적용 근거와 범위

- 원본: https://github.com/vmc-inner-circle/k-style-ui-ux/tree/68afa2ea125d0db6b378e5f7ba03b0e4dd010d8e
- 적용 가이드: 해당 커밋의 `plugins/k-style-ui-ux/skills/go/SKILL.md`, `core/principles.md`, foundation 컴포넌트·토큰·체크리스트.
- 요청된 개인 계정 경로는 조회되지 않아 GitHub의 현재 저장소와 기여자를 확인했다. 전역 스킬 설치가 아니라 이 프로젝트에 가이드·CSS·라이선스 있는 자산을 적용했다.
- 기존 Next.js 앱을 개선하는 요청이므로 새 정적 HTML 캔버스를 만드는 절차를 React 라우트와 반응형 CSS로 옮겼다. 원본 foundation CSS 위에 앱 레이아웃·dialog·플레이어 어댑터를 추가했다. 글꼴은 외부 요청 없이 로컬 Pretendard를 제공한다.
- 새로운 경쟁 서비스 조사나 사용자 인터뷰 결과로 간주하지 않는다. 별도 리뷰 에이전트는 가이드 기준으로 탐색·가족별 기억·재생 시트·접근성·fixture 정합성을 검토했다.

## 화면과 의도

1. `/demo`: 보관함. 최근 일기, 전체 목록, 날짜·장소·제목 검색, 장소 필터, 빈 결과 초기화.
2. `/demo/[id]`: 일기 상세. 읽기와 원문을 전환하고 가족별 기억을 구분한다.
3. 듣기 시트: 선택한 발화의 원문과 구간 표시, 재생·일시 정지·탐색·종료·오류 재시도. 닫으면 오디오를 멈추고 Blob URL을 해제하며 초점을 돌려준다.
4. 화면 설정: 파랑 기본, 코랄·민트 대안. 선택은 이 브라우저에 저장한다. 스킬의 라이브러리에서 myrealtrip, airbnb, triple 팔레트를 derive.py로 생성했다. 기본은 회색 배경/흰 블록의 구분이 있는 파랑으로 정했다.

표현: 한글 산세리프, 큰 제목, 회색 배경과 흰 블록, 충분한 터치 영역, 중립색 필터, 행동에만 브랜드색. 장식 사진이나 동작하지 않는 메뉴를 추가하지 않는다.

## 제품 명세와의 관계

`docs/product-brief.md`, `specs/001-family-trip-memory/spec.md`의 범위를 줄이지 않는다. 자유 발화·LLM 분류·원본 보존·차량과 휴대폰 양쪽 읽기/듣기는 계속 첫 버전 요구사항이다. 이번 변경은 읽기/듣기 경험의 **합성 미리 보기**이고 backend 기능 완료로 표시하지 않는다.

모든 일기·구성원·장소는 고정 합성 자료다. 8초 합성 시험음은 구간 재생 검증용이며 실제 녹음이나 STT 결과가 아니다. 8초는 제품 녹음 길이 제한이 아니다. 차량 캡처, 실제 주차 판정, 인증, AI 생성, 기기 동기화는 이 UI 변경으로 검증되지 않는다. 스마트폰 녹음 기능을 추가하지 않았다.

## 후속 수정: 기록 연월과 전체 녹음

사용자 피드백으로 장소 필터 칩을 제거했다. 기본은 기록 연월별 목록이며 기간 선택과
날짜·장소·제목 검색을 조합한다. 기존 녹음 팝업은 ‘원래 이야기’ 탭 안의 전체 녹음 플레이어와
시간순 원문 목록으로 대체했다. 각 원문 구간을 누르면 해당 시점부터 전체 끝까지 이어
재생하고 현재 구간을 색과 문구로 함께 표시한다. 가족별 기억의 듣기도 같은 플레이어를 쓴다.

기존 k-style 토큰/컴포넌트를 유지하고 `ui-ux-pro-max`의 키보드 탐색·초점 가이드를 참고했다.
월별 탐색은 사용자가 특정 대안을 지정한 것이 아니라 이번 구현에서 선택한 기본값이다.
[후속 검증](../evidence/timeline-validation.md)을 참고한다.

## 차량 네이티브 적용 — 2026-11-09

기존 웹의 회색 배경·흰 블록·파랑 행동 버튼·한글 산세리프·월별 탐색을 Android View로 옮겼다.
`VehicleTheme`은 공통 색·간격·모양·눌림/초점/비활성 상태를 제공한다. 흰 버튼 글자의 대비를 위해
파랑은 기존 brand-text(#0a70c2)를 사용한다. 64dp 버튼, 스크롤 가능한 탐색 영역, 명시적 밝은 테마를 사용한다.
신규 팔레트나 웹 화면을 띄우는 WebView가 아니라, 기존 캡처/STT/저장 포트에 연결한 네이티브 화면이다.
`ui-ux-pro-max`의 터치 간격·상태 피드백·큰 글자/레이아웃 체크를 참고했다.
[실행 증거와 미검증 범위](../evidence/vehicle-ui.md)를 참조한다.
