# 원본 타임라인·TTS·주행 음성

상태: 에뮬레이터 구현 / 실차 정책 검증 잔여. 정리일: 2026-11-13. 작업 브랜치: dev.
이번 문서는 사용자 승인에 따라 기존 구현·기록을 사후 분리했다. 구현 전에 작성된 명세라고 주장하지 않는다.
이전 식별자: FR-001, FR-003, FR-009; C019, C020, C025, C026, C028, C032, C038. [전체 색인](../README.md), [이전 명세](../archive/2026-11-13-before-split/spec.md).

## 사용자 가치와 수용 시나리오

1. 같은 완성 일기로 TTS→원본→일시정지→TTS 전환 시 겹치는 재생과 자동 재개가 없다.
2. 주행 전환 시 편집/사진은 숨겨지고 진행 중 음성은 허용 범위에서 유지된다. UNKNOWN/중단/주차 복귀를 검증한다.

## 현재 요구사항

- **PLAY-001**: 양쪽 기기에서 전체 원본을 재생·일시정지·탐색하며 발언을 선택하면 그 구간부터 원본 끝까지 재생한다. 시각이 없는 이전 발언은 시간을 추정하지 않고 전체 재생을 제공한다.
- **PLAY-002**: 현재 발언·재생 위치·파형을 실제 재생 시간에 맞추고 진행 부분을 주황색으로 표시한다. 원본 내려받기는 모바일 음성 영역에서 제공하며 기기 미지원은 안내한다.
- **PLAY-003**: 차량의 완성 일기 TTS/원본은 기본적으로 선택한 한 편만 재생한다. PLAY-013의 전체 반복을 켠 경우에만 정상 완료 후 다음 일기로 넘어간다. 정지·오류·늦은 콜백·포커스 상실 후 자동 재개하지 않는다. 모바일 TTS는 현재 구현 범위가 아니다.
- **PLAY-004**: 주행 청취 화면에는 기본 일기 읽어주기 한 플레이어만 표시한다. 듣기 방식 탭은 목록에서 다음에 재생할 방식을 선택한다. 탭만 바꾸면 현재 재생과 왼쪽 정보는 그대로 유지되고, 목록의 일기를 명시적으로 선택했을 때 기존 엔진 종료 후 선택한 방식으로 시작한다.
- **PLAY-005**: 이전/재생/정지 또는 일시정지/다음은 접근성 이름을 가진 아이콘이다. 원본은 일시정지 위치부터 재생하며 TTS 일시정지/재개는 PLAY-011을 따른다. 정상 종료 설명은 숨기고 오류는 알린다.
- **PLAY-006**: 주행에서는 허용된 녹음·청취만, 주차에서는 본문·사진·검토를 제공한다. UNKNOWN/권한/동의 상실 시 중단하며 모의 입력을 실차 허용으로 간주하지 않는다.
- **PLAY-007**: 사용자가 시작한 녹음·청취는 서비스가 소유해 내비 화면에서도 유지한다. 오디오 포커스 정책을 지키고 캡처와 청취는 동시 시작하지 않는다. 미녹음 D→P 복귀는 녹음 홈이다.

- **PLAY-008**: 사용자가2026-11-13 Downloads에 제공한1280×720 PNG4개(주행 대기/녹음 중/녹음 멈춤/일기 듣기)를 주행 화면의 새 정본으로 한다. 왼쪽 메뉴를 제거하고 상단 로고·주행 상태, 큰 녹음/듣기 선택, 녹음 시간·실제 입력 파형과2개 조작 버튼을 제공한다. `이 순간 표시`는 제외한다. 주행 듣기는 현재 제목·날짜와 PLAY-012의 날짜순 제목 목록을 허용하며 본문·사진·전체 인식문 탐색·검색은 계속 차단한다. 주행 녹음의 최신 인식문 표시는002 REC-007을 따른다. 일기 낭독/그날의 목소리 전환은 같은 기록을 유지하고 녹음 화면으로 돌아갈 때 재생을 종료한다. UI 전환은 녹음을 자동 시작하지 않는다.
- **PLAY-009**: 원본의 진행 막대/시간은 실제 재생 위치와 원본 길이에 연결한다. 현재 Pleos TTS3.3.1은 pause/seek/총길이/구간 위치 API가 없어 낭독은 시작 콜백 이후의 실제 경과시간과 `낭독 중` 상태를 표시하며 총길이·진행률을 추측하지 않는다. 낭독의 일시정지/재개는 PLAY-011의 문장 단위 보관으로 제공한다. 녹음 중에는 청취를 제공하지 않고 멈춘 파형은 회색 직선으로 고정한다.

- **PLAY-010**: D→P 전환 시 사용자가 시작한 TTS/원본 청취를 이어가며 차량 주차의 녹음·일기·설정 화면에 공통 재생바를 표시한다. 현재 제목/듣기 방식/실제 진행 상태와 PLAY-011의 이전/재생·일시정지/다음·방식 전환과 종료를 제공한다. 재생 중 화면 탐색은 음성을 암묵적으로 종료하지 않으며 녹음 시작은 재생이 종료된 후에만 가능하다. 재생바가 내용·조작을 덮지 않는다. UNKNOWN/동의 상실은 기존 중단 정책을 유지한다.

- **PLAY-011**: 주행과 주차 공통 플레이어는 이전·하나의 재생/일시정지 토글·다음 아이콘과 `일기 읽어주기`/`그날의 목소리` 전환을 제공한다. 동일한 완성 일기와 날짜순 목록을 유지한다. 원본은 정확한 위치, TTS는 SDK에 pause/seek가 없으므로 중단 응답을 확인한 뒤 현재 문장부터 재개한다. TTS 문장 단위 재개임을 접근성 설명/도움말에 명시하며 준비·중단 응답 대기 중 중복 조작을 막는다. 일시정지 중 다음/이전은 자동 재생하지 않는다. 주행 방식 탭은 재생과 독립적이며 이전/다음/재생 토글은 실제 현재 재생 방식을 제어한다. 명시적 항목 선택은 선택한 목록 방식으로 시작하고, 재생 중 이동은 기존 엔진 종료 확인 후 새 항목을 시작한다. 명시적 종료/포커스·동의·UNKNOWN 상실은 재개 상태를 폐기한다. 주차 공통 바의 방식 전환은 같은 일기를 멈춘 상태로 선택하며 재생 버튼을 눌러 시작한다. 한 일기의 다음 문장은 정상 완료 후 이어지며 다음 일기는 PLAY-013을 따른다.
- **PLAY-012**: 주행 청취 목록은 완성된 일기의 제목·날짜를 최근 날짜부터 내림차순(같은 시각은 ID 순)으로 표시한다. 최초 현재 일기와 앞8개·뒤8개까지 가져오며, 끝에 도달하면 해당 방향으로8개씩 추가한다. 인접 경계가 있으면 처음에도 더 적게 반환한다. 불투명 기록 ID 커서, 중복 방지, 앞쪽 추가 시 보던 위치 유지, 로딩·오류/재시도·양끝 상태, 오래된 응답 무시를 제공한다. 현재 재생 항목은 스크롤 목록 위에 고정하고 테두리/아이콘/접근성 current로 강조한다. 나머지는 최근순으로 표시하며 중복 표시하지 않는다. 고정 항목이 페이지 커서를 바꾸지 않는다. 목록을 누르면 그 일기를 선택한 목록 방식으로 재생하며 포커스/주행 정책을 재검사한다. 목록 응답에는 본문·사진·전체 인식문을 넣지 않는다.

- **PLAY-013**: 전체 반복은 처음에 꺼져 있다. 반복 화살표 아이콘과 접근성 이름/눌림 상태로 켜고 끄며 주행·주차 공통 플레이어가 같은 값을 쓴다. 켜진 동안 TTS와 원본 모두 현재 날짜순 목록의 다음 항목으로 진행하고 마지막 일기를 정상적으로 마치면 첫 일기로 돌아간다. 일기가 한 편이면 같은 일기를 반복한다. 반복을 끄면 현재 재생 중인 한 편을 마치고 멈춘다. 반복 아이콘 왼쪽의 현재 순서/전체 개수 표시는 제거한다. 탭 전환·옵션 변경 자체로 재생하지 않는다. 명시적 종료/오류/포커스 상실 후 자동 재개하지 않는다.
- **PLAY-014**: 확인할 이야기의 미완성 원본은 `확인할 이야기`와 녹음 날짜로 표시하여 완성 일기와 구분한다. 일기 상세의 읽어주기 버튼은 재생 시작 후에도 같은 자리에 남고 해당 일기의 일시정지/이어읽기를 제어한다. 다른 일기의 재생 상태를 상세 버튼에 적용하지 않는다.

- **PLAY-015**: 주차 공통 플레이어의 방식 버튼은 `일기 / 목소리`, 상태 머리는 `일기 · 일시정지` 또는 `목소리 · 재생 중`처럼 짧게 표시한다. 이전/재생·일시정지/다음/반복 버튼의 상시 배경·테두리를 제거하고 SVG 기호만 보인다. 기존 터치 영역·disabled·키보드 focus·접근성 이름·반복 활성 표시와 실제 재생 동작을 유지한다.
