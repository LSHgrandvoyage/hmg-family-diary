# 원본 타임라인·TTS·주행 음성 — 구현 계획/현재 구조

2026-11-13 사후 정리. [명세](spec.md)와 [작업](tasks.md)을 함께 읽는다.

## 현재 구조

`PlaybackService`, `RecordingService`, `VehicleInteractionPolicy`, `MainActivity`가 상태와 미디어를 소유하고 faithful WebView는 허용된 화면을 그린다. 원본 시각은 SDK 구간과 PCM 기준을 이용하며 임의 화자 추정은 하지 않는다.

공통 데이터·계약은 [001](../001-family-trip-memory/plan.md)에서 연결한다. 변경 시 사용자를 위한 수용 조건부터 명세에 반영한다.

## 의존성과 검증

헌장2.2.0의 원본 불변·가족 격리·주행 제한·검증 환경 구분을 유지한다.
연결/미디어/화면을 가로지르는 변경은 상대 기능 ID를 명시한다. 기존 증거와 이번 실행 결과를 구분한다.
신규 작업은 spec → plan/계약 → tasks → 정합성 검토 → 구현 → 검증/증거 → dev 커밋 순서다.

## 미해결 의존성

- 실차 마이크·내비/통화 오디오 포커스·핸들/CCP 입력 검증.
- 공식 플랫폼의 주행 음성/원본 보관·전송 허용 확인.

## C043 — 모바일 연결 흐름과 주행4개 화면 (구현 전 계획)

새 driving.js/CSS 화면 구성요소를 상태 기반으로 렌더링한다. native에서 완성 기록의 제한된 메타데이터(현재 제목·날짜·길이·순서·다음2개)만 제공하고 권한/상태 불명 시 비운다. 메타데이터는 캐시하고 기록 변경 시 무효화한다. PlaybackService는 TTS 시작 콜백의 monotonic 시각만 추가하며 미디어 생명주기/포커스 계약은 유지한다. 녹음하기로 돌아가기는 명시적 listenExit 명령으로 재생을 종료한다.

정합성 검토:003 SYNC-009/006 UX-008/004 PLAY-008~009가 소유한다. 사용자 참조 이미지가 이전 C032 레이아웃을 대체한다. 일기 본문 접근·가족 격리·동의·원본 보존·TTS 정지 후 처음부터 재생은 유지한다. 원본 길이를 TTS 길이로 쓰지 않는다. 신규 메타데이터 계약과 오류/빈 목록/주차 복귀·오디오 전환을 검증하고 라이트/다크 및 모바일 작은 폭에서 확인한다.

## C044 — 주행 자막·동의 화면·창 크기·재생 연속성 (구현 전 계획)

PlaybackService의 현재 파일/방식/제목/진행을 공통 playback 상태로 내보낸다. 신규 parked playback 컨트롤은 서비스 현재 파일을 직접 제어해 다른 선택 기록으로 전환하지 않는다. 기존 화면 내 TTS 바를 공통 바 하나로 통합하고 render/view/read 경로에서 배경 오디오를 의도치 않게 중지하거나 선택을 바꾸는 지점을 조정한다. 녹음 시작은 idle 검사를 유지한다.

정합성 검토: 헌장2.3.0에 사용자 요청의 제한된 주행 STT 표시 예외를 먼저 반영했다.002 REC-007,004 PLAY-010,006 UX-009,008 ENTRY-007이 소유하며 원본·DB·동기화 보관 계약은 바꾸지 않는다. 연결 상태를 녹음 동의로 간주하지 않는다. 개인정보 안내는 현재 동작의 프로토타입 안내로 한정하고 법적 적합성을 주장하지 않는다. 실제1682×1210 창/1280×720 참조·양쪽 테마·모바일·D/P 전환·동의 미선택/부분/전체/해제·주행 bridge 제한을 검증한다.

## C045 — 재생 통합·목록 페이지·STT 줄 흐름 (구현 전 계획)

PlaybackService가 문장 분할·현재 문장·일시정지 요청/확정·재개를 소유한다. Pleos TTS3.3.1의 stop/onStop와 generation 검사를 사용하며 onDone/늦은 콜백이 정지 후 자동 진행하지 않게 한다. native listenAction/listenPage를 주행·주차 공용 제한 오디오 계약으로 제공한다. 현재 선택·방식은 하나로 유지하며 음성 종료 응답 뒤 전환한다. native 메타데이터 목록은 날짜/ID로 정렬하고 처음8+현재+8, 커서 이전/이후8씩 반환한다. UI는 요청 세대/중복/경계와 앞쪽 삽입 스크롤 보존을 관리한다. 전체본문 bridge 허용을 넓히지 않는다. 합성40개 목록과 cache-only 음성/TTS 에뮬레이터 검사로 상태/경계를 검증한다.

정합성 검토: 헌장2.4.0과002 REC-007/008,004 PLAY-011/012,006 UX-010을 대조했다. 사용자 요청이 기존 다음2개·TTS 전체 재시작·최근4문장 표시를 대체한다. 실제 마이크 인식 정확도와 실차 허용을 합성 UI 결과로 주장하지 않는다. 데이터/동의/원본 보존·포커스 상실 중단은 유지한다.

## C046 — 선택 재생·제목과 목록 (구현 전 계획)

목록 선택 방식과 활성 재생 방식을 분리한다. PlaybackService가 자동 이어듣기(default false)와 원본 목록을 소유해 화면 이탈에도 동일하게 동작한다. 종료 ack/generation/포커스 검사를 유지한다. 날짜순 native 커서는 내림차순으로 변경하고 UI 고정 현재 행은 별도 컨테이너로 분리하여 페이지 경계가 변하지 않게 한다. 상세 버튼은 현재 파일/모드에 결합하고 숨김 CSS를 제거한다. 초안 제목은 날짜 기반 상태명을 표시한다.

정합성 검토:004 PLAY-013/014,002 REC-009와003 기존 revision 동기화 계약을 대조했다. 원본 불변·목업 본문·주차 편집 제한을 유지한다. 방식 탐색은 AI 생성 요청이 아니다. 실차 허용 주장은 추가하지 않는다. 합성 페이지/두 테마/상세 버튼과 SDK 재생 완료·모드 전환·제목 보존을 검증한다.

## C047 — 전체 반복과 순서 표시 제거 (구현 전 계획)

2026-11-14. PLAY-008/013을 먼저 수정한다. 기존 autoAdvance 옵션과 주행/주차 공유 상태를 유지하면서 PlaybackService의 정상 완료 경로만 마지막→0으로 순환시킨다. 한 편 목록도 같은 완료 경로를 쓴다. 다음/이전 버튼의 수동 경계와 현재 항목 고정·날짜순 목록은 바꾸지 않는다. 아이콘 접근성 이름/도움말을 전체 반복으로 바꾸고 현재 순서/전체 개수 DOM과 렌더링을 제거한다.

정합성 검토: 사용자의 명시적 반복 요청이 C046의 마지막 종료 정책을 대체한다. 반복 OFF의 한 편 종료, stop/generation/오디오 포커스/UNKNOWN 중단은 유지한다. 원본·DB·동기화·AI 생성 계약 변경은 없다. 합성 음성과 SDK TTS로 마지막→첫 항목, 한 편 반복, OFF 후 완료, 명시적 종료를 확인하고 양쪽 테마에서 숫자 표시 제거를 검증한다.

## C048 — 연결/저장 알림과 간결한 공통 플레이어 (구현 전 계획)

2026-11-14. parked-player의 텍스트와 transport CSS만 바꾼다. 모드 전환·음성 생명주기·반복 로직은 유지한다. 일반 상태에서는 투명 배경을 쓰고 hover/focus/반복 ON을 색과 focus outline·SVG 강조로 표시한다.

정합성 검토:003 SYNC-010,004 PLAY-015,006 UX-011을 대조했다. 단순 연결 등록과 전송 성공을 혼동하지 않도록 상세 오류를 보존한다. 원본 불변·동기화 제한·목업·주행/편집 보호를 유지한다. 실제 네트워크/실차 확인을 합성 UI 결과로 주장하지 않는다. 각 변경의 중복/실패/초기 상태·월 경계·두 테마를 검증한다.

## C050 — 차량 상호작용·상태 피드백 (구현 전 계획)

`PLAY-016`: 행 앞의 날짜를 연도 + MM.dd로 구성하고 native 요약에 연도/월일/요일을 추가한다. 재생 guard 이유와 UI 대기/중복 조작 방지를 연결한다. 사용자 원래 Check failed의 정확한 발생 지점은 재현 증거와 구분한다.

정합성 검토: SYNC-010/011, REC-010, PLAY-011/012/016, UX-012, DEP-009의 화면 계약을 연결한다. 실제 SDK/STT/오디오 포커스 제한을 우회하지 않고 합성 UI와 에뮬레이터 검증을 구분한다. 기존 사용자 기록·DB를 초기화하지 않는다.

## C051 — 낭독 진행·화면 전환 (구현 전 계획)

MainActivity의 ticker에서 원본 여부와 무관하게 foreground 미디어 상태를 갱신한다. PlaybackService에서 문장 수·현재 문장과 정상 완료 결과를 소유하고 숫자 메타데이터만 bridge로 전달한다. 주행 진행바/주차 경과시간을 실제 상태에 연결하며 자연 완료와 명시적 종료를 구분한다. 공식 Pleos3.3.1 이벤트/로컬 AAR 공개 API를 근거로 총길이를 추정하지 않는다.

정합성 검토: PLAY-011/013/016의 재생·종료 경계, UX-012의 주행 콘텐츠 제한과 모션 줄이기를 유지한다. 목업·실제 TTS 계측과 합성 UI 검증을 구분하며 개인 데이터를 사용하지 않는다.

## C052 — 가사형 낭독 문장 (구현 전 계획)

PlaybackService가 실제 onStart에서 표시 인덱스를 확정하고 현재±2개의 제한된 문장만 반환한다. 자연 완료의 마지막 문장 창은 보존하고 다른 재생·종료·오류에서는 폐기한다. native 상태에 제한된 배열을 추가하되 목록 응답/전체 본문 권한은 넓히지 않는다. 실제 SDK 문장 경계만 사용하고 단어별 시각은 추정하지 않는다.

정합성 검토: 사용자 명시적 주행 텍스트 범위 변경을 헌장2.5.0/제품 정의/PLAY-018에 반영했다. 원본·전체 본문 검토·사진·UNKNOWN 차단과 PLAY-011/013/016/017의 미디어 수명은 유지한다. 실차 허용을 추론하지 않는다.
