## C042 — 기본 Compose와 제출용 앱 연결 (구현 전 계획)

현재 서버 정적 JS는8자리를4칸에 표시하고 저장소는6칸에1자리씩 표시한다. 이미지 재빌드가 누락된 배포 문제이며 SYNC-002의6자리 구현을 다시 만들지 않는다.

- `configure-runtime.mjs`는 Node24 내장 기능으로 `.env.runtime` 주소를 읽고 기본 Compose proxy의 공개 CA만 복사한다. CA로 health를 검증한 뒤 기존 contest의 `chagok_server_config` 입력으로 전달한다. run-as·개인키·목업 토큰을 사용하지 않는다.
- 현재 서버를 새 소스로 재빌드/재생성한다. DB·미디어 볼륨은 유지한다. 제공 중인 JS/CSS와 저장소 해시 일치, 실제 제공 자산에서6칸·선행0 표시를 독립 브라우저로 검증한다. 가족 API는 합성 응답으로 대체한다.
- README는 기본 서버+제출용 앱과 기존 probe 디버그 흐름을 구분한다. 팀원용 configure-release 경로는 그대로 둔다.
- 실행 검증은 실제 맥북 기본 서버와 현재 contest 앱의 설정 확인창까지다. 가족 연결/자동 동기화 완료는 사용자의 코드 입력 및 별도 검증 없이는 주장하지 않는다. 기존 실행 중인 에뮬레이터를 중지하거나 앱 데이터를 지우지 않는다.

정합성 검토: DEP-004/007과 SYNC-002의 실행 경로 보완이다. APK 내부 동작·6자리 계약·원본 보존·명시적 서버 적용 경계를 변경하지 않는다.
