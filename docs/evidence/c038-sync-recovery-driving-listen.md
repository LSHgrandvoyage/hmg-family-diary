# C038 원본 전송 복구와 주행 청취

2026-11-13, 차곡차곡0.2.2(code3). 기존0.2.0 Windows 사용자 신고: 연결 직후 본문만 수신, 원본 업로드 차단, 사진 수신 안 됨. 차량에서 약2초 원본은 정상 재생됨. 사용자 원본/로그는 수집하지 않았다.

## 재현 원인과 수정
서버 WAV 검사 `(payload/align/sampleRate)*1000`은64064바이트 PCM을2001.9999999999998ms로 계산해 내림 시2001ms가 된다. 차량은 정수 연산으로2002ms를 저장하므로 AUDIO_MISMATCH로 거절한다. 같은 증상을 만드는 오류를 합성 자료로 재현했다. 사용자 실제 파일의 정확한 길이/서버 오류코드는 확인하지 않았으므로 해당 사용자 건의 원인을 단정하지 않는다.

- WAV 길이를 `(payload*1000)/(align*sampleRate)`로 계산한다. SHA/불변 원본/포맷 검증은 유지한다. 원본 파일을 변환하거나 서버 snapshot을 임의 수정하지 않는다.
- 기존 audio 단계의 일반 검증 실패는1회 재검증하고 cursor를 다시 조회한다. 명시적 지금 동기화도 AUDIO_MISMATCH 원본을 재시도한다. snapshot 충돌과 삭제 tombstone은 재시도로 풀지 않는다. 서버 코드별로 실패 안내를 구체화한다.
- 원격 audio_ready=false여도 동일 해시의 원본을 이미 가진 차량은 사진을 수신한다. 로컬 일기/원본은 보존하고 원격 음성을 준비 완료로 표시하지 않는다. 새 수신 기기는 원본이 준비되기 전 기록을 완료로 가져오지 않는다.
- 주행 플레이어는 기본 일기 이어 듣기 한 개다. 원본으로 전환하면 같은 완성 일기를 유지한다. 재생 중 전환은 기존 엔진 종료 후 시작하고, 정지/일시정지 상태 전환은 자동 시작하지 않는다. 원본 재생/일시정지와 TTS 재생/정지를 SVG로 제공하며 정상 종료 문구는 숨긴다. 오류·녹음 상태 피드백은 유지한다.
- 이전/다음은 완성 일기 목록을 사용한다. 주행 화면의 날짜/목록을 캐시해 상태 갱신마다 모든 원본을 다시 해시하지 않는다.
